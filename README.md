## Оформлення замовлень

Сторінка лишається GitHub Pages, а персональні дані й секрети обробляє окремий Node.js-сервіс на VPS. Він:

- приймає замовлення, зберігає їх у захищеному журналі та надсилає повідомлення в Telegram;
- віддає підказки Нової пошти для відділень і поштоматів;
- відповідає в Telegram на `/orders` або `/stats` зі статистикою за сьогодні, місяць і весь час.

Конфігурація сервісу лежить у `server/`. Значення з `server/order-service.env.example` задаються лише на сервері у `/etc/donetsk2014-orders.env`; їх не потрібно додавати в Git. Перевірка перед розгортанням:

```bash
npm test
```
